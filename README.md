## Features

- Animated welcome intro and a floating, tilting 3D portrait
- Frosted-glass cards with cursor-tracking 3D tilt and light
- Morphing shapes, staggered entrances and smooth scroll animations
- Expandable project details, resume preview and one-click contact routes
- Fully responsive, with reduced-motion support
- One self-contained HTML file: no build step, no dependencies

## Tech Stack

**HTML5, CSS3 and vanilla JavaScript.** Fonts: Anton, Space Grotesk and Inter from Google Fonts. Hosted on Vercel.

## Run Locally

```bash
git clone https://github.com/DSFAHAD/fahad-hameed-portfolio.git
cd fahad-hameed-portfolio
# open index.html in your browser, or serve it:
python -m http.server 8000
```

## Deploy

1. Push `index.html` to a GitHub repository.
2. Import the repository in [Vercel](https://vercel.com) with the **Other** framework preset.
3. Click **Deploy**. Every push to `main` redeploys automatically.
